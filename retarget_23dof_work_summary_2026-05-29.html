Kimodo 23DOF G1 重定向与环境修复总结

日期：2026-05-29
分支：kimodo-init-5090
基准提交：097442e fix: add RTX 5090 support and optimize docker configuration

本轮工作的核心目标是验证：Kimodo 34DOF/34-joint G1 生成动作，是否可以降维后驱动 23DOF Unitree G1 骨架，并能在 MuJoCo 中正常查看。

1. Docker 与本地运行环境

  • 调整 docker-compose.yaml，让 demo 和 text encoder 服务更适配本地 GPU 调试。
  • 加入 HuggingFace/Transformers 离线环境变量，避免容器启动时卡在外网请求。
  • 为 text encoder 和 demo 服务分别设置 CUDA 可见设备，便于在多 GPU 机器上拆分运行。
  • 延长 text encoder 健康检查窗口，降低模型加载时间较长时误判失败的概率。
  • 将 docker_requirements.txt 中 py-soma-x 从 Git 安装改为固定版本安装，降低构建时网络依赖。

2. G1 23DOF 重定向脚本

新增 kimodo/scripts/retarget_g1_23dof.py，用于将 Kimodo G1 34-joint / 29-DOF 输出转换为 23DOF G1 qpos。

  • 保留 root 7 列：xyz + quat(wxyz)。
  • 保留双腿 12 个关节、腰 yaw、左右手臂各 5 个关节。
  • 去掉 waist roll、waist pitch、left/right wrist pitch、left/right wrist yaw。
  • 输出 NPZ 字段 qpos_23dof，shape 为 [T, 30]。

3. MuJoCo 可视化问题定位

发现 g1_23dof.urdf 中 floating base joint 被注释掉，因此 MuJoCo 加载后是 fixed-base 模型，model.nq == 23。

原 visualizer 在 qpos_23dof 为 30 列、模型只要 23 列时直接截断前 23 列，导致 root xyz/quaternion 被当成腿部关节角输入。这是“腿飞到天上”的直接原因之一。

已修复 research/retarget_23dof_g1/visualize_mujoco_23dof.py：当输入是 [T, 30] 而目标模型是 fixed-base 23DOF 时，自动使用 qpos_23dof[:, 7:]。

4. 研究目录与诊断工具

新增研究目录 research/retarget_23dof_g1/，集中放置 23DOF 验证文档和工具。

文件 作用
README.md 记录目标、问题树、测试路径和验收标准。
check_23dof_npz.py 无 GUI 检查 NPZ 是否能喂给 23DOF MuJoCo 模型，并报告关节顺序、几何高度范围和限位问题。
npz_global_to_23dof.py 纯 NumPy 转换器，用仓库自带 G1 demo NPZ 的 global_rot_mats/posed_joints 生成 23DOF qpos NPZ，不依赖 torch。

5. 生成的 23DOF 示例

生成了 8 个可用于 MuJoCo 查看动作的示例 NPZ，位于 research/retarget_23dof_g1/examples_23dof/。 

python research/retarget_23dof_g1/visualize_mujoco_23dof.py research/retarget_23dof_g1/examples_23dof/01_single_text_prompt_23dof.npz

建议优先查看：

  • 01_single_text_prompt_23dof.npz
  • 02_multi_text_ee_constraint_23dof.npz
  • 05_root_path_23dof.npz
  • 06_root_waypoints_23dof.npz
  • 07_text_terrain_23dof.npz

03_full_body_keyframes、04_ee_constraint、08_text_object 在 headless 检查中出现轻微 ankle 限位超出，可用于后续评估是否需要 clamp。

6. MuJoCo 交互启动方式

动作播放：

python research/retarget_23dof_g1/visualize_mujoco_23dof.py research/retarget_23dof_g1/examples_23dof/01_single_text_prompt_23dof.npz

官方静态 viewer：

python -m mujoco.viewer --mjcf research/retarget_23dof_g1/g1_23dof_mujoco_viewer.urdf

交互：鼠标左键旋转，鼠标右键平移，滚轮缩放，Space 暂停/继续，ESC 退出。

8. 后续建议

  • 先以 fixed-base 23DOF URDF 验证姿态是否正常。
  • 若要验证 root 轨迹行走，需要先准备 floating-base 的 23DOF MJCF/URDF。
  • 若 MuJoCo 中仍有明显关节异常，下一步应比较 mujoco_rest_zero convention 和 locked-joint 固定变换。
